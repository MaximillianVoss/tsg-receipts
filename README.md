# Квитанции ТСЖ

Учебное приложение на C# для формирования квитанций жильцам товарищества собственников жилья. Практическое задание УП.07, тема 11. Версия 1.1.0.

## Состав решения

Решение `КвитанцииТСЖ.sln` содержит пять проектов:

| Проект | Назначение |
|---|---|
| Исходники/ТСЖ.ПредметнаяОбласть | Модели, decimal-расчёты и округление |
| Исходники/ТСЖ.Приложение | Сервисы, контракты хранилища и экспорта, проверка прав |
| Исходники/ТСЖ.Инфраструктура | JSON-хранилище, PBKDF2, PDF с кириллицей |
| Исходники/ТСЖ.Интерфейс | Русский интерфейс Windows Forms |
| Тесты/ТСЖ.Тесты | Автоматические проверки MSTest |

Пространства имён `Tsg.Domain`, `Tsg.Application`, `Tsg.Infrastructure`, `Tsg.Desktop`, `Tsg.Tests` сохранены для совместимости исходного кода. Имена решения, проектов, файлов проектов и папок русифицированы.

## Получение исходников

Публичный репозиторий: [MaximillianVoss/tsg-receipts](https://github.com/MaximillianVoss/tsg-receipts).

Установите Git и выполните в PowerShell:

```powershell
git clone https://github.com/MaximillianVoss/tsg-receipts.git
cd tsg-receipts
```

Затем откройте `КвитанцииТСЖ.sln` в Visual Studio или выполните команды ниже. При клонировании не требуется доступ к учебным документам или рабочим данным автора.

## Сборка и запуск

Требуется Windows x64 и .NET SDK 10. При первом восстановлении тестовых пакетов нужен интернет. Команды выполняются из корня этой исходной папки:

```powershell
dotnet build ".\КвитанцииТСЖ.sln" -c Release
dotnet test ".\КвитанцииТСЖ.sln" -c Release
dotnet run --project ".\Исходники\ТСЖ.Интерфейс\ТСЖ.Интерфейс.csproj"
```

В Visual Studio откройте `КвитанцииТСЖ.sln` и выберите `ТСЖ.Интерфейс` запускаемым проектом. Подходит Visual Studio с поддержкой .NET 10 и компонентом разработки классических приложений .NET.

Демонстрационные логины: `admin`, `accountant`, `resident`, `resident2`; учебный пароль `Demo123!`. Все записи начальной базы вымышлены. Для контрольного расчёта войдите бухгалтером, выберите счёт 1001 и месяц 2026-10: начисления 2700 ₽, начальный долг 500 ₽, к оплате 3200 ₽.

Обычная база хранится в `%LOCALAPPDATA%\TsgReceiptDemo\state.json`. Для отдельного набора данных:

```powershell
dotnet run --project ".\Исходники\ТСЖ.Интерфейс\ТСЖ.Интерфейс.csproj" -- --data ".\artifacts\demo\state.json"
```

Повреждённый файл не заменяется демонстрационными данными автоматически. Одну базу одновременно открывает один экземпляр приложения. Платёжные действия локальные и учебные, без внешнего платёжного провайдера.

## Автономный выпуск Windows

```powershell
dotnet publish ".\Исходники\ТСЖ.Интерфейс\ТСЖ.Интерфейс.csproj" -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:PublishTrimmed=false -o ".\artifacts\win-x64"
```

Результат — `artifacts/win-x64/КвитанцииТСЖ.exe`. Среда .NET включается в выпуск. Для экспорта PDF используется системный шрифт Arial. Сборка автономной версии не изменяет C#-код.

## Проверка интерфейса

```powershell
dotnet run --project ".\Исходники\ТСЖ.Интерфейс\ТСЖ.Интерфейс.csproj" -- --verify-ui ".\artifacts\новая-проверка"
```

Для каждой проверки укажите новую папку. Будут созданы отдельная демобаза, снимки реальных WinForms-форм, PDF и `ui_verification.json`. Проверяются обработчики кнопок, расчёт, права, сохранение и повторное открытие. Это автоматический прогон, отдельные ручные тест-кейсы заполняются после ручного выполнения.

## Подготовка исходников к публикации

В этой папке находятся исходники и фиксированные версии NuGet-зависимостей. `bin`, `obj`, `artifacts`, рабочие JSON, пользовательские настройки и результаты запусков исключены из контроля версий через `.gitignore`. Сервер, ключи доступа и производственные данные приложению не нужны. Это локальная учебная демонстрация: промышленная эксплуатация и приём реальных платежей не предусмотрены.
